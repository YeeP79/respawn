## Spec

**Question:** S11 proved 49 of 50 plugins co-exist, but the payload was SNWCreations'
curated pack — so what it proved is that **the pack's** versions co-exist. Ours are newer
everywhere they overlap and have never been loaded together.

| | pack (S11) | ours (`mods-platform.txt`) |
|---|---|---|
| MetaMod:Source | 2.0.0-dev+1380 | 2.0.0-git**1410** |
| SourceMod | 1.12.0.**7221** | 1.12.0-git**7251** |
| Left4DHooks | 1.161 | `f90ae5e6` (**1.168**) |

**Pass bar:** The same 49 plugins and 13 extensions load, with no new failure, and the
S12 order path still works. Fail = anything that loaded on the pack's platform stops
loading on ours.

**This decides:** Whether `mods-platform.txt`'s pins are the ones the variant ships, or
whether the manifest has to be walked back to the pack's floor.

---

## What was actually done

`lab/s15-our-pins/Dockerfile` layers the three platform pieces **over** the pack's
assembled tree rather than rebuilding the whole stack from scratch. That is deliberate:
half the manifest's 43 entries are AlliedMods forum attachments with no stable download
URL — the same reason S11 used the pack at all — and layering isolates the variable to
the three components actually in question.

Built `FROM l4d2-acc:s13`, so this is the image the modded variant will ship (S13's C++
runtime swap included) and not a hypothetical one.

**One thing this changes beyond three files:** SourceMod's tarball carries its own copies
of the stock plugins, so layering replaces the pack's 7221 stock set with the 7251 one.
That is the right direction — a mixed SourceMod (7251 binaries against 7221 stock
plugins) is a state nobody tests upstream — but it is worth knowing this build moves more
than the three names in the table.

## Answer

**PASS.** Every count matches S11 and every failure S11 had is gone — 49 plugins, 13 of
13 extensions, and **no SourceMod error log at all**, where S11 had one. S12's VScript
order path and S14's slot machinery both still work.

---

## Consequences

**1. `mods-platform.txt`'s pins are the shipping pins.** S11 consequence 4 is closed: the
newer set is not merely compatible, it is strictly better here — the one thing the pack's
platform could not do (load Accelerator) is fixed, and nothing regressed.

**2. The pack stays the payload for the other 40 entries**, and stays second-hand. This
did not make those reproducible; it made the platform underneath them ours. The
distinction is the honest one to carry into the variant.

**3. Four images now stack in a line**, each adding exactly one variable:
`left4devops/l4d2` → `l4d2-full:s11` (the pack) → `l4d2-acc:s13` (runtime swap) →
`l4d2-full:s15` (our platform). Keep it that way — the reason every failure in this
session was attributable in one step is that no two variables ever moved together.

**No spike spawned.**
