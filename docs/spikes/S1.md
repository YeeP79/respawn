## Spec

**Question:** Can one derived image carry MetaMod:Source, SourceMod, Left4DHooks, All4Dead2 and Stripper:Source, and boot to a playable map with all of them loaded?

**Pass bar:** `meta list` shows MetaMod and SourceMod loaded; `sm plugins list` shows Left4DHooks, All4Dead2 and Stripper running; the server reaches a map and answers A2S; **zero** plugin load errors and zero `[SM] Unable to load` lines in the boot log.

**This decides:** Whether the proposed base template is real, and what actually belongs in it. A component that will not load here does not get to be in the base.

**Why this spike exists:** The whole base-and-branches structure assumes these five coexist. Nothing has compiled or loaded them together — the versions come from a third-party pack that tracks 2026 releases, not from a build we ran. L4D2 plugins break on Valve updates, so a stack that is individually current can still fail as a set.

## Prior art

Searched 2026-08-28.

- [Left 4 DHooks Direct 1.168 thread](https://forums.alliedmods.net/showthread.php?t=321696) — **read in full** (via Chrome; Cloudflare blocks automated fetching). v1.168 dated 18-Jun-2026, reports 2,297 servers. Detours dynamically, rescanning on map change, so an unused base install should be close to free. States outright: *"Player slots is unsupported. Use the L4DToolZ Metamod plugin."*
- [SNWCreations/l4d2-modded-server](https://github.com/SNWCreations/l4d2-modded-server) — **skimmed**. Pins SourceMod 1.12 / MetaMod:Source 2.0.0 and bundles this same set, which is the strongest evidence they coexist. Not verified by us.
- [How to make a L4D2 server with mods (2026)](https://moddingcommunity.com/blog/how-to-make-a-l4d2-server-with-mods/) — **read in full**. Gives the install paths (`plugins/` `.smx`, `gamedata/`, `extensions/` `.so`) and the `autoexec.cfg` vs `server.cfg` split.
- [left4devops/l4d2 image docs](https://github.com/Left4DevOps/l4d2-docker) — **read in full**. Reads custom content from `/addons/` and config from `/cfg/server.cfg`, so a derived image needs no entrypoint replacement.

Not found: anyone running this stack on Fargate, or in a container with a read-only game dir.
