# CS 1.6 KZ map manifest — one map per line: <name> <type> <difficulty> <url>
#
# COLUMNS
#   type        kreedz.com's own classification: Climb | Bhop | Mix | Slide | Special
#   difficulty  kreedz.com's official tier, Beginner -> Death. This is the community's
#               own rating, not an inference — stronger provenance than the TFC set,
#               where no rating system existed and tiers had to be read out of prose.
#   url         kreedz.com API. GET /api/map/<name> returns the zip as an attachment.
#
# SELECTION: shortlisted from the 1,148 recordable maps in /api/map/browse, then ranked
# by the download count on /api/map/detail and taken top-N per difficulty tier. Weighted
# toward Beginner..Medium, where a mixed-skill group actually plays, with a few harder
# maps as a ramp. Non-recordable maps are excluded: the community does not count times
# on them, which is the wrong default for a server built around times.
#
# ADDING A MAP IS A TWO-SIDED CHANGE — see apps/tfc/variants/modded/maps.txt and the
# CLAUDE.md gotcha. Server half: fetch + rebuild + deploy, or `changelevel` fails.
# Client half: publish to FastDL, or joiners crawl at HLDS's 8 kB/s cap.
