# --- Respawn: Valheim — QUALITY OF LIFE base --------------------------------
# Included by every variant above the admin rung. Convenience only: nothing here adds
# content, and nothing here changes the balance of the game.

# THE ENTIRE SET IS WORLD-SAFE, AND THAT IS LOAD-BEARING. A variant whose plugins are all
# world-safe stamps its worlds `vanilla`, so a world can run here and still be moved back
# to the plain vanilla server. Adding ONE unflagged plugin to this file makes every world
# that runs on every variant including it `modded` — permanently, and for all of them.
#
# WHICH IS WHY THIS FILE MUST STAY JOTUNN-FREE. Jotunn ships four embedded asset bundles
# and calls AddPrefab; it is a prefab-registration library and cannot honestly be asserted
# world-safe. Anything depending on it belongs in a content rung, which is one-way anyway.
# MSchmoecker/MultiUserChest is the mod this costs us — it declares Jotunn, so it lives in
# the content rungs rather than here.
#
# Every entry below was checked against its own package: no RegisterPrefab call, no
# embedded world assets, no Jotunn dependency.
#
# <namespace>/<package> <version> [world-safe]
