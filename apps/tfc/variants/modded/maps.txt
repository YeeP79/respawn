# TFC modded map manifest — one map per line: <name> <url>.
#
# ADDING A MAP IS A TWO-SIDED CHANGE. Do both, or it is broken in one direction:
#
#   SERVER  add the line here, then `pnpm tfc:content:fetch`, then rebuild+deploy.
#           The maps are COPYed into the image, and the image tag is a content hash
#           over the Dockerfile plus every COPYed file — so a new map changes the tag
#           and forces exactly one rebuild. Skip this and `changelevel <map>` fails:
#           the server does not have the file, whatever is in S3.
#
#   CLIENT  `pnpm tfc:content:publish <bucket> <profile>` to mirror it to FastDL.
#           Skip this and the map loads fine but every joining player pulls it at
#           HLDS's own 8 kB/s transfer cap and will usually time out instead of
#           joining. S3 is a pre-play step, NOT a runtime dependency: the server
#           never reads from the bucket, so an empty or stale bucket only makes
#           joins slow — it cannot stop the server starting.
#
#   VOTE    add it to mapcycle.txt too, or mapchooser never offers it.
#
# Source: tfcmaps.net archive (all 20 listed there as Working). The three mixed-case
# archives (58THV2, K_ConcMap, rjumpTFC) are lowercased on extract: GoldSrc on Linux
# will not resolve `changelevel` against mixed case.#
# COLUMNS: <name> <category> <url>
# Category drives mapcycle generation (scripts/generate-mapcycles.sh), which is how
# "skill maps only" is expressed. The FILES cannot be organised — GoldSrc requires a
# flat tfc/maps/*.bsp and wads at tfc/ root — so selection is the thing to organise.
#   conc    scout/medic concussion-jump tracks
#   rocket  soldier rocket/grenade-jump tracks
#   mixed   both, or multi-skill (DM arena + jump course)#
# COLUMNS: <name> <category> <source> <url>
#
# SOURCE records WHY a map earned its place. There is no rating system for TFC skill
# maps, so this is the nearest thing to a bar — capture it when adding, or the next
# person adds on vibes and the set quietly degrades:
#
#   favorite    named on tfcmaps.net's own Favorites list for the Skill game type
#   rated-5     JMC's TFC Map Zone 5-star (only one map in the whole skill category)
#   rated-4     JMC's TFC Map Zone 4-star (only one)
#   community   recommended by name in community threads (usually as a good starter)
#   catalogued  a substantive catalogue entry calling out difficulty or design
#   sequel      direct sequel to a map already in this set with stronger provenance;
#               no independent write-up of its own, so the parent is the evidence
#
# `favorite`, `rated-5` and `rated-4` are the strongest signals and feed the generated
# favorites.txt cycle. `catalogued` is the weakest — fine for filling out a rotation,
# not enough on its own for a short one.
